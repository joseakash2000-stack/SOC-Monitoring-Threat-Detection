# SOC Monitoring & Threat Detection Lab

A hands-on Security Operations Center (SOC) lab focused on network threat detection, security monitoring, alert analysis, log investigation, and SOC dashboard development.

## Overview

This project demonstrates a practical SOC monitoring environment built using Suricata as the network intrusion detection system (IDS) and Splunk as the SIEM platform.

The lab was developed in a controlled virtual environment using Kali Linux and Ubuntu. Network traffic was monitored using a bridged network adapter, allowing security events generated by Suricata to be collected and analyzed in Splunk.

## Objectives

- Build a basic SOC monitoring environment
- Monitor network traffic for suspicious activity
- Configure Suricata IDS detection rules
- Generate and analyze security alerts
- Forward Suricata EVE JSON logs to Splunk
- Investigate security events using SPL
- Identify source and destination IP addresses
- Analyze HTTP, ICMP, SSH, and scanning activity
- Classify and investigate security alerts
- Build a SOC monitoring dashboard
- Practice SOC L1 alert triage and investigation workflows
